Memorize Ará — Conexão Araxá

Projeto Acadêmico & Gamificação Social

🎯 Proposta de Valor:
Plataforma gamificada desenvolvida para promover a conscientização cultural, turística e histórica de Araxá, alinhada diretamente aos seus 8 eixos oficiais (Social, Educação, Saúde, Segurança, Esporte, Turismo, Cidadania e Cultura).
⚡ Tecnologias Utilizadas:
  • HTML5 Semântico & CSS3 Moderno: Grid e Flexbox com design responsivo (celular, desktop e totens).
  • JavaScript Vanilla (ES6+): Sem dependência de bibliotecas externas, carregamento instantâneo.
  • Web Audio API: Síntese sonora procedural nativa no navegador.
  • Web Storage API: Persistência local offline para o ranking Top 5.
  • Git & GitHub Pages: Controle de versão e deploy contínuo em nuvem.
👥 Equipe do Projeto:
Desenvolvido para apresentação acadêmica — Conexão Araxá.
